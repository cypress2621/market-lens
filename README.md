# 币析 · Market Lens

在本机运行的 Binance USDT 现货与永续合约分析网站，使用真实公开行情，可选连接自己的只读账户。不会自动开仓、平仓、划转或提现。

## 安装与启动

需要 Node.js 22.13 或更高版本及 npm。

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:3000 。Windows 安装依赖后也可双击“启动网站.cmd”；“停止网站.cmd”仅停止该脚本启动的服务。

如果需要代理，把 .env.example 复制为 .env.local，在 BINANCE_HTTP_PROXY 中填写自己的本机 HTTP 代理地址；留空时直接连接。仓库不包含任何个人代理配置。

## 功能

- **我的持仓**：可选连接 Binance 标准 USDT 合约只读账户，同步实际数量、价格及交易所返回的强平价，自动分析当前持仓依据、结构止损、两档止盈及 1/4/24 小时复核点。当前依据不冒充历史入场理由。
- **合约机会**：扫描全部通过基础条件的 USDT 永续合约，分为已确认、接近触发、持续观察；记录本次服务观察到的新增和持续信号。报价过期时隐藏候选，缺失数据单独说明。
- **成本估算**：同时展示观察区中点目标和当前买卖报价的盈亏比，可调整手续费、滑点和持仓时间；资金费根据公开结算周期估算，仅计支付方向，不预先计入收款收益。
- **市场研究**：成交额、振幅、涨跌榜、K 线及技术指标；可切换 1/4/24 小时和涨跌门槛的历史频率参考。
- **预警**：站内提醒、用户启用的声音和桌面通知。网页、本地服务及电脑须保持运行，休眠和后台限制会影响送达。

## 账户与隐私

公开行情无需 API Key。账户连接只在自己本机的网页填写 Key 和 Secret；不要提交至 GitHub 或发送给他人。

- 仅接受通过权限检查的系统生成 HMAC 只读 Key；拒绝交易、提现、划转权限。签名接口仅限 API 权限、账户及仓位风险的 GET 请求。
- Key / Secret、账户快照、自动计划和预警记录仅存在本地服务内存中；断开连接或停止服务后清除。服务重启后需要重新连接。
- 用户自定义规则保存在 .local-data/position-rules.json，含 Key 的哈希分组及个人规则，仍属于私人数据。该目录被 Git 忽略；不要手动上传。
- 浏览器 localStorage 只用于通知偏好。日志、环境文件、数据库、截图导出及构建缓存不要提交。源代码测试中的账户和价格均为构造样本。
- 仓库不包含运行中的私人数据、个人部署标识或原机器路径。新的使用者应使用自己的配置。后续提交前仍需检查暂存区，.gitignore 无法阻止强制添加或已跟踪文件。

账户功能仅在本地 npm run dev 中启用。npm run build 用于构建验证，不包含可部署的私人账户服务；不要将账户桥接暴露到公网。

## 策略说明

稳健模式：24h 成交额至少 1 亿 USDT、价差至多 5 基点、上市至少 30 天。积极模式：3,000 万 USDT、10 基点、7 天。全部合格合约参与技术扫描，没有前 30/40 名上限。

趋势取已收盘 1h/4h EMA20/50；使用 RSI、ATR、量比和 15m 确认。合约目标按观察区中点的风险距离构造为 1.5R/2.5R，资金费筛选按每 8 小时折算。接近触发包含观察区内未确认及距离不超过 0.5 ATR 的等待候选。服务每轮完成后 90 秒刷新，信号历史在服务重启时重置。

这些规则未经过盈利回测或预测胜率校准。历史频率不是未来上涨概率保证；止损参考不是交易所止损单，目标不保证在指定时间到达。账户价格或技术数据过期时会明确提示。
